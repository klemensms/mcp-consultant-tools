**Date:** 2026-06-04

## Overview

First beta of the v33 line. Two functional changes (core + azure-devops) plus supporting documentation. Selective bump — only the two changed packages move to `33.0.0-beta.1`; the remaining 23 packages stay at `32.0.0`.

## Changes Implemented

- **feat(core): `mcp-warm-secrets` CLI** (`75ad4b0`). New CLI in `@mcp-consultant-tools/core`. Reads an `.mcp.json`, resolves all `op://` references across every server in a single 1Password prompt per account into the shared encrypted cache, so concurrently-launched MCP servers start without each triggering its own prompt. Opt-in via a documented shell wrapper; no impact on default behaviour or biometric users. `isOpSignedIn()` guard refuses to run when 1Password is not signed in so a failed resolve can't poison the cache. New files: `src/warm-secrets-cli.ts`, `src/helpers/warm-secrets.ts`, `src/helpers/__tests__/warm-secrets.test.ts`; `bin` entry `mcp-warm-secrets`. 90/90 core tests pass.
- **fix(azure-devops): read-only `sync-work-item-to-file`** (`5904b1b`). Replaced `autoConvertFieldsToMarkdown` (which PATCHed ADO, set field format to Markdown irreversibly, and bumped revision) with pure in-memory `convertFieldsToMarkdownInMemory`. Removed the re-fetch and revision bump. Added `turndown-plugin-gfm` so HTML tables → Markdown pipe tables. Added `htmlHasTable` detection surfacing `conversionWarnings` for lossy tables. Preserved `skipAutoConvert=true` behaviour. Touches `src/services/sync-service.ts`, `src/sync/html-converter.ts`, `src/sync/turndown-plugin-gfm.d.ts`, `src/tools/sync-tools.ts`.
- **docs(azure-devops): read-only pull + lossy-table protocol** (`2409806`). Corrected sync docs across `packages/azure-devops/CLAUDE.md`, `docs/documentation/AZURE_DEVOPS.md`, the local-markdown-items guide, and `docs/technical/AZURE_DEVOPS_TECHNICAL.md`.
- Supporting docs (non-package): `fc5e1d2` config docs (VS Code-first), `a066171` CLI inventory refresh (19→21, added Fabric + audit CLIs), `0b2187b` dead-reference repoint, `b3b4773` 1Password 2FA-bypass token publish note.
