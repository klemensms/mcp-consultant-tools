## Overview

Security republish of the figma package. The previously published figma tarballs (`latest` 32.0.0 and `beta` 32.0.0-beta.4) ship an internal example file key in the compiled tool descriptions (`build/tool-examples.js`). This iteration republishes figma as **33.0.0 to both `beta` and `latest`** with synthetic example identifiers, and makes the v33 `si-investigation` → `investigation` sticky-category rename backward compatible on input. Because `@mcp-consultant-tools/meta` pins figma at exactly `32.0.0`, **meta is republished as 32.0.1** with its figma dependency bumped to `33.0.0` — otherwise `meta@latest` would keep pulling the old figma tarball.

figma jumps 32.0.0 → 33.0.0 directly (it was not part of the earlier v33 beta wave); the major bump reflects the category rename.

## Changes Implemented

- `packages/figma/src/figma/extractors/semantic-extractor.ts` — new exported `LegacyStickyCategory` type (`"si-investigation"`) and internal `normalizeStickyCategory()`; `categorizeStickyColor` and `extractSemanticData` accept the legacy alias in `stickyColorOverrides` values and normalize it to `investigation` at both override-lookup sites. Output type `StickyCategory` is unchanged — `si-investigation` is never emitted.
- `packages/figma/src/tools/figma-tools.ts` — `get-figma-semantic`'s `stickyColorOverrides` zod enum additionally accepts `"si-investigation"` (documented as deprecated alias in the parameter description).
- CLI (`mcp-figma-cli get-semantic --sticky-overrides`) parses overrides as raw JSON and routes through `extractSemanticData`, so it inherits the normalization with no CLI change. Previously a legacy value passed via CLI would have been emitted verbatim; now it is normalized.
- `tests/test-figma-semantic-extractor.js` — two new regression tests: alias via `categorizeStickyColor` overrides and alias via `extractSemanticData` options, both asserting emitted category `investigation`.
- `docs/technical/FIGMA_TECHNICAL.md` — documents the deprecated input alias.
- Version bumps: figma `32.0.0` → `33.0.0`; meta `32.0.0` → `32.0.1` (figma dependency `32.0.0` → `33.0.0`, no code change).
