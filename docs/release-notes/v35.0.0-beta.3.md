# Release Notes: v35.0.0-beta.3

**Date:** 2026-07-12
**Branch:** `release/35.0`
**Status:** Published to beta

> Per-iteration agent-level detail. The user-facing single source of truth is [`v35.0.0.md`](v35.0.0.md).

## Overview

A read-only tooling expansion consolidating a long-running port wave (PR #4, 16 commits) into `release/35.0`: four new read-only MCP servers and diagnostic/analysis suites added to five existing servers, plus a `meta` registration fix and repo hygiene. No breaking changes — every addition is read-only unless explicitly gated behind a documented `*_ENABLE_*` flag, and no new required environment variables are introduced.

## Changes Implemented

### New servers (first publish, 35.0.0-beta.1)
- **`azure-defender`** — Microsoft Defender for Cloud: secure score, security assessments, regulatory compliance, recommendations, attack paths (12 read-only tools). Shared `AZURE_*` SP, needs Security Reader.
- **`entra-id`** — Entra ID app-registration credential-expiry + API-permission audit (2 read-only tools). Graph `Application.Read.All`.
- **`message-center`** — M365 Service Health + Message Center (7 read-only tools). Graph `ServiceHealth.Read.All` + `ServiceMessage.Read.All`.
- **`code-review`** — provider-agnostic repository review across Azure DevOps / GHE / GitHub App: .NET EOL, NuGet vulnerability audit, complexity metrics, GH Packages (10 read-only tools).

### Tools added to existing servers
- **`azure-sql`** — Query Store performance (6), sessions + space (8), index health (4, incl. gated `sql-create-fk-indexes` behind `SQL_ENABLE_INDEX_CREATE`). New vitest harness (94 tests).
- **`azure-management`** — Resource Graph, log streaming, detectors (11 read-only). New vitest harness (71 tests).
- **`azure-devops` / `azure-devops-admin`** — build-timeline issues, git branches/refs, read-only variable-group diffs (10 read-only, domain-split).
- **`powerplatform` / `powerplatform-core`** — `scan-flow-health` + `get-flow-inventory` (2 read-only), app-only via the Dataverse `workflow` + `flowrun` tables. Pure `flow-health.ts` logic module (25 new tests, zero mocks).
- **`azure-data-factory`** — `adf-query-debug-pipeline-runs` (1 read-only) via the undocumented `queryDebugPipelineRuns` ARM action; honest `truncated` reporting, status-casing normalization. New vitest harness (17 tests).

### Fixes & hygiene
- **`meta` duplicate-safe registration** — a colliding tool name no longer aborts a package's remaining registrations (first package wins the name; the rest register). 9 unit tests in a new `meta` vitest harness.
- **`.env.example` (×5) → one `.mcp.json.example`** — consolidated config reference (all 24 servers, every env var annotated). The 5 files that referenced the old file were updated.
- **`author` → `Klemens Stelk`** across all `package.json` (LICENSE's MIT upstream attribution left intact).
- **`sic_` publisher-prefix example → `contoso_`** — sanitized a client-identifier placeholder across docs + source examples.

### Version changes
- First publish at `35.0.0-beta.1`: `azure-defender`, `entra-id`, `message-center`, `code-review`.
- `35.0.0-beta.1` (from 34.0.0): `powerplatform-core`.
- `35.0.0-beta.2`: `azure-sql`, `azure-management`, `azure-devops`, `powerplatform`, `azure-data-factory`.
- `35.0.0-beta.3`: `azure-devops-admin`, `meta`.
- `meta` exact-pin deps updated to match; `powerplatform` → `powerplatform-core@35.0.0-beta.1`.
