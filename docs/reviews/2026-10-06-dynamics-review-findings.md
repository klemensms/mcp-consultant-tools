# Dynamics review findings checked against this repo

A review of a separate copy of our PowerPlatform (Dataverse) MCP server produced nine findings, each with a reference fix in that copy. This file records whether each one applies to this repo, with evidence, the proposed change, any risk to capability and the size. Item 10 is an extra note from our own commit reviewer.

**Rule applied throughout:** our servers stay unlocked. Bugs and security holes are fixed; no table or column allow-lists, no row caps, no feature removed.

**Status:** proposals only. Nothing below has been changed yet; each item waits for the maintainer's decision.

Paths are relative to `packages/powerplatform-core/src/` unless stated.
