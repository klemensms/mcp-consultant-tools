# Agent work log

Append-only record of what coding agents have done in this repo, newest first.

Written only by `log-append.py` (the `/log` command). Never edit it by hand: a
PreToolUse hook blocks direct edits because concurrent sessions clobber each
other's entries. Merges are conflict-free via the `merge=union` line in
`.gitattributes`, which keeps every line from both sides. If you ever do see a
conflict here, the resolution is always "accept both".
