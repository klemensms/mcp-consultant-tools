- 05:12 [author:: klemensms] [branch:: release/35.0] Fixed a response-dropping race in the InMemoryTransport HTTP wrapper in powerplatform-data, powerplatform and sharepoint: six call sites, two per package (POST /mcp and the REST-to-MCP bridge). The JSON-RPC response listener was installed AFTER `clientTransport.send()`. InMemoryTransport.send() is synchronous, so a known method is safe (the SDK answers it a microtask later, by which time the listener exists) but an unknown method is not: Protocol._onrequest emits MethodNotFound inline during the send, while onmessage is still undefined, and the reply goes into the transport's _messageQueue, which nothing drains after start().
